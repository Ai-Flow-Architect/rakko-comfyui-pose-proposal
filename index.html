4. 既知バグマトリクス（対応手順とセットで保証）

バグ対応
Qwen-Image-Edit 黒画像出力（Issue #11865）ノードバージョン固定 ＋ 設定値テンプレ適用
1024 正方形以外で破綻（Issue #243）事前リサイズノード挿入 ＋ アスペクト比保持処理
Blackwell GPU の DLL エラーCUDA / cuDNN バージョン整合 ＋ 公式 wheel 切替
VRAM 不足GGUF Q5 → Q4 自動切替 ＋ tiled VAE 適用

未知バグへの 3回試行プロトコル

5. セキュリティ

  • TeamViewer 無人アクセス用 16文字パスワード 発行・作業後変更を平丸様に依頼
  • Python venv で完全分離（既存環境を汚さない）
  • 作業前に snapshot 保存（万一の切り戻し対応）

6. Phase 2 接続プラン（将来拡張）

Phase 1 で ComfyUI workflow をサブグラフ化＋batch_wrapper.py 雛形を同梱しておくので、 Phase 2 は Gradio UI を追加するだけで「複数キャラの一括処理 Web ツール」として完成します。 Phase 1 の構造を活かしたまま拡張できる設計です。
